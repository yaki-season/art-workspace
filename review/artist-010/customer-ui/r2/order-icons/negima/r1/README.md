# Negima order icon — R1

손님 주문 대기 패널의 미수령 음식 슬롯에 들어가는 네기마 꼬치 단일 에셋 후보다.

- 검수 대상: [review-negima-fhd-r1.png](review-negima-fhd-r1.png)
- 실제 투명 에셋: [order-icon-negima-r1.png](assets/order-icon-negima-r1.png)
- 규격: `192×192`, straight alpha, 네 모서리 alpha `0`
- 범위: 닭고기·파가 교차하는 네기마 꼬치 한 개와 온전한 대나무 꼬치만 포함
- 제외: 수량·체크·말풍선·게이지·접시·손님·패널·다른 음식·문자·배경
- 상태: `approved-by-user`; runtime 등록 금지

사용자가 `2026-07-27`에 이 자산을 승인했다. 주문 대기 패널 R3의 첫 미수령 음식 슬롯에는 이
이미지만 연결한다. 수량은 DOM `xN`, 완료 상태는 이 아이콘을 원형 체크 DOM으로 교체한다.
전체 UI·재조립 승인 전에는 runtime 등록하지 않는다.
