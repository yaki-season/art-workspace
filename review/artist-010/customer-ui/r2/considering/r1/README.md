# Customer considering UI — R1

한 손님이 메뉴를 고르는 동안 머리 위에 표시하는 완결형 말줄임표 에셋이다.

- 검수 대상: [review-considering-fhd-r1.png](review-considering-fhd-r1.png)
- 실제 투명 에셋: [customer-state-considering-r1.png](assets/customer-state-considering-r1.png)
- 규격: `192×144`, straight alpha, 네 모서리 alpha `0`
- 범위: 말풍선·세 점·꼬리만 포함한다. 문자·수치·게이지·손님·음식·배경은 포함하지 않는다.
- 상태: `approved-by-user`; runtime 등록 금지

사용자가 `2026-07-26`에 이 자산을 승인했다. runtime 등록은 전체 UI·재조립 승인 전까지
금지하며, 다음 단일 승인 단위는 대기 타이머 UI다.
