# Artist 007 future station concept review

- spec 기준: `GPL-004 v1.1.0`, `DAT-001 v3.0.0`, `UI-002/SYS-002 v3.0.0`, `ART-002/ART-003 v3.2.0`
- 상태: 후속 후보 스테이션 조작 컨셉 r1, 사용자 시각 검수 대기
- 공통 구조: 실제 좌석 순서의 상단 주문 카드, 중앙 조작대, 하단 공유 완성품 목록
- 확정 범위: 조작 관계와 화면 구조
- 미확정 범위: 해금 시점, 정확한 메뉴명, 수치, 최종 캠페인 포함 여부

| 후보 스테이션 | 컨셉 | 포함한 플레이 |
|---|---|---|
| `ST-INSTANT-SERVE` | [`instant-serve/r1`](station-concepts/instant-serve/r1/generated.png) | 메뉴 픽토그램 선택, 넓은 접시 스냅, 주문 자동 연결, 오태그 복귀, 완성품 이송 |
| `ST-FRYER` | [`fryer/r1`](station-concepts/fryer/r1/generated.png) | 한입 재료 선택, 반죽 원형 드래그, 투입, 온도·색·기포 판정, 건지기, 덜 익음 복귀와 탄 음식 폐기 |
| `ST-SASHIMI` | [`sashimi/r1`](station-concepts/sashimi/r1/generated.png) | 직선 칼질, 두께·직진성 판정, 넓은 부채꼴 플레이팅 앵커 |
| `ST-PLATING` | [`plating/r1`](station-concepts/plating/r1/generated.png) | 접시 선택, 넓은 구성 앵커, 오배치 복귀, 가니시 마감, 완성도 품질 판정 |
| `ST-HIGHBALL` | [`highball/r1`](station-concepts/highball/r1/generated.png) | 얼음→원액 홀드→탄산→레몬 순서, 비수치 비율 밴드, 중단·넘침·오주문 복구, 완성품 이송 |

모든 화면의 자물쇠는 후보 상태를 뜻한다. 특정 메뉴를 확정하지 않도록 음식은 일반화된 픽토그램과 실루엣으로 표현했다. 이 파일들은 manifest/runtime 승인본이 아니다.
