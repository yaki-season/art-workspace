# Artist 000 — D1 손님 주문 접수 전체 화면 R1

- 상태: `approved-by-user`
- 화면: `D1-ORDER-001` 주문 접수 직후, 네기마 `x3`·생맥주 `x1` 모두 대기 중
- 규격: `1920×1080` FHD
- 생성: built-in imagegen의 전체 장면 후보 1장 + 승인 주문 UI DOM/CSS 조립

## 범위

이 검수판은 D1의 첫 손님 화면 하나만 다룬다. 한 명의 츠키오카, 단일 연속 바 카운터,
중앙 단일 대문과 그 너머의 밤 골목, 네기마·생맥주 주문 대기 패널만 포함한다. 조리 화면,
완성 음식·생맥주, 다른 손님, 수량 이외의 문자, 전환 UI는 포함하지 않는다.

## 검수 항목

1. 단일 츠키오카와 `네기마 x3 + 생맥주 x1`이 D1 첫 주문으로 명확히 읽히는가.
2. 바 안쪽 카메라 → 단일 바 카운터 → 손님 좌석 → 중앙 단일 대문 → 밤 골목의 공간 순서를 지키는가.
3. 카운터가 하체를 완전히 가리고, 주문 패널이 얼굴·손을 가리지 않는가.
4. 패널 외피·두 주문 아이콘은 기존 승인본을 그대로 쓰고, 수량·게이지는 DOM/CSS 책임으로 남는가.

2026-07-28 사용자가 이 R1을 승인했다. 이 승인은 D1 주문 접수 전체 장면의 구도·의미·승인
주문 UI 조립을 대상으로 하며, 개별 runtime asset 승인·최적화·manifest 등록을 뜻하지 않는다.

## 재생성 금지

다음 화면 작업은 먼저 기존 승인 전체 화면을 screen ID·카메라·상태·필수 구성요소 기준으로
검색한다. 충족하는 화면이 있으면 새 전체 화면을 생성하지 않고 그 승인 화면에서 필요한
complete layer·standalone raster·DOM/CSS 계약을 분리·재조립한다. 새 전체 화면은 해당 상태가
기존 승인 화면으로 만들어지지 않는다는 근거를 기록한 경우에만 만든다.
