# ST-GRILL-FINISHED-TRAY R4

`grill.finished` 공용 완료품을 서빙 전 보관하는 빈 completed-food rack이다. 좌측 승인 `ST-GRILL-WAITING-RACK R2`의 철/황동 재질과 수납 cavity를 직접 파생했다.

R4는 user correction에 따라 far rim `184px`, near rim `218px`의 top-to-bottom 원근을 적용해 그릴보다 더 세워 보이게 했다. placement slot은 보류 지시대로 FHD `(1534, 130, 218, 342)`를 유지한다.

음식·꼬치·model·shader·UI·runtime 등록은 포함하지 않는다. `superseded-by-user-direction` (2026-07-30): 사용자 지시에 따라 금속 tray 형태를 중단하고, 음식 없는 대나무 김밥말이 resting mat R5를 다음 단일 후보로 제작한다.
