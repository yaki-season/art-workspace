# ST-GRILL-FINISHED-TRAY R6

`grill.finished` 공용 완료품을 서빙 전 잠시 올려두는 빈 대나무 김밥말이 resting mat이다. 음식과 꼬치는 runtime 동적 조합이며, 이 파일에는 포함하지 않는다.

R5 원본을 새로 생성하지 않고 투명 PNG로 직접 투시 변환했다. 왼쪽 transform origin `(1534, 130)`은 고정했으며, 폭을 오른쪽으로 15% 넓히고 작은 뒤로 눕힘·우측 기울기·반시계 회전을 적용했다. 가시 알파 범위는 `(1534, 123, 266, 354)`이다.

상태: `approved-by-user` (2026-07-30). `runtimeRegistrationAllowed`는 계속 `false`다. 음식 model/shader의 master-camera 톤 교정은 이 mat과 분리된 다음 PM gate다. 최종 소비 화면·runtime handoff·manifest 등록은 별도 최종 승인 후에만 가능하다.
