# ST-GRILL-FINISHED-TRAY R3

`grill.finished` 공용 완료품을 서빙 전 보관하는 빈 completed-food rack이다. 조립 완료 생 네기마를 보관하는 좌측 `ST-GRILL-WAITING-RACK R2`와 동일한 얕은 cavity·가까운 rim·상부 시점·black-iron/brass 수납 계열을 사용한다. 두 rack의 차이는 목적과 위치뿐이며, R3는 우측 상단 FHD `(1534, 130, 218, 342)`에 놓인다.

기존 승인 left rack의 투명 출력 영역 `(85,265,340,530)`을 최근접 축소해 파생했으며, 새 raster 생성·음식·꼬치·model·shader·UI는 포함하지 않는다.

`superseded-by-user-feedback` (2026-07-30). 사용자 정정에 따라 같은 rack 계열을 유지하면서 그릴보다 더 세워진 far/near rim 원근의 R4를 별도 검수한다. x 간격 변경은 보류하며, 음식 model/shader가 PM의 station-camera gate를 통과하기 전까지 tray+음식 합성이나 runtime handoff를 진행하지 않는다.
