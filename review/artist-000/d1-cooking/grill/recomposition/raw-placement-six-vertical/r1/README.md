# D1 연속 석쇠 세로 6꼬치 실제 GLB 결합 R1

승인된 연속 석쇠 R2 위에 승인된 네기마 구성 GLB를 실제 slot node로 조립한 검수 후보이다.

- 구성: 생 네기마 6꼬치, 세로 방향, 하나의 가로 행, 각 꼬치 `닭→파→닭→파→닭`
- 규모: 석쇠 깊이를 채우도록 base scale `190`, 승인된 구성물 상대 scale `1.40`
- 제외: 새 래스터, 익힘, 불꽃, 연기, 전달, UI, 텍스트, runtime 등록
- 상태: `superseded-by-master-r1` — 사용자가 석쇠 위 네기마 상태 자산을 먼저 정의하도록 전체 그릴 장면 재구성을 지시했다. 이 후보는 삭제하지 않고 판단 이력으로 보존한다.
