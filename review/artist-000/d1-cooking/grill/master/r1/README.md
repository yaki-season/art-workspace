# CM-GRILL-STATION-D1-REBUILD R1

`CM-GRILL-STATION-R1`을 구성·광원·작업면 기준으로 삼아 다시 만든 D1 그릴 전체 장면 검수본이다.
이 파일은 runtime asset이 아니며, 이후 분리하는 그릴·석쇠 위 네기마 상태·집게·VFX·tray의 기준 장면이다.

- D1 규칙: 물리적 6-lane body 중 중앙 두 칸만 활성, 나머지 네 칸은 비활성.
- 활성 꼬치: 두 꼬치 모두 세로로 나란히 놓인다. 왼쪽은 익는 중, 오른쪽은 집게가 잡아 180도 뒤집는 중이다.
- 상태 기준: 왼쪽 대기 tray의 생, 중앙 익는 중/뒤집기, 오른쪽 완성 tray의 적정, 폐기 tray의 완전 탄.
- 제외: 타레·부채·손님·드링크·문자·수량·품질 단어·runtime 등록.
- 상태: `superseded-by-r2` — 사용자가 연속 석쇠·조립 완료 대기 rack·폐기 버튼을 포함한 구도를 지시했다. R1은 판단 이력으로만 보존한다.
