# CM-GRILL-STATION-QUEUED-SELECTION R3

R2의 전체 작업면을 보존하고, 좌측 대기 rack의 생 네기마 세 꼬치 각각에 독립된 icon-only 선택 pad를 추가한 전체 그릴 장면이다.

- 중앙: 칸·lane·slot marker가 없는 하나의 연속 석쇠와 하나의 charcoal bed.
- 조리: 같은 석쇠 위 세로 네기마 두 개. 하나는 익는 중, 하나는 집게로 180도 뒤집는 중.
- 대기: 조립 결과 생 네기마 3개. 그림에 남은 꼬치별 황동 pad 3개는 사용자 정정으로 **추출·runtime 사용 금지**인 master 내부 시각 실험이다. 실제 D1 제어는 대기 rack 아래 단일 DOM `네기마` 선택이다.
- 우측: 적정 완성 tray, 완전 탄 discard tray, 아이콘만 있는 `UI-DISCARD-GRILL` 버튼 skin.
- 상호작용: D1 `네기마` 선택과 폐기 제어의 hit area·상태·수량·문구·키보드·접근성·D1 가시성은 DOM 책임이다. 꼬치별 pad는 기준이 아니다.
