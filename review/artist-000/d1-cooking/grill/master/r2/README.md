# CM-GRILL-STATION-CONTINUOUS-GRATE R2

R1의 톤앤매너와 작업면을 유지하면서 사용자 피드백을 반영해 다시 만든 전체 그릴 장면이다.

- 중앙: 칸·lane·slot marker가 전혀 없는 단일 연속 석쇠와 하나의 charcoal bed.
- 조리: 두 네기마가 세로로 나란히 있으며, 하나는 익는 중이고 하나는 집게로 180도 뒤집는 중이다.
- 대기: 조립 화면에서 넘어온 생 네기마 3개가 left waiting rack에 쌓여 있다. 런타임 수량은 빈 rack과 개별 꼬치로 동적 합성한다.
- 우측: 적정 완성 tray, 완전 탄 discard tray, 아이콘만 있는 `UI-DISCARD-GRILL` 버튼 skin.
- 폐기 제어: DOM이 문구·확인·접근성·입력과 D1 숨김 규칙을 담당한다. 이 그림의 버튼은 normal-service visual reference다.
- 상태: `superseded-by-r3`; 사용자 요청으로 좌측 대기 꼬치별 선택 패드를 추가한 R3가 현재 검토 대상이다. runtime 등록 금지.
