# BG-WORKSPACE-GRILL R2

사용자가 선택한 `CM-GRILL-STATION-EMPTY-BASE R1`의 중앙 연속 석쇠를 유지하고, 왼쪽의 빈 tray만
`BG-WORKSPACE-GRILL R1` 작업면으로 교체한 D1 그릴 full-frame base다. 좌우 생꼬치·완성품은 별도
아트가 아닌 DOM inventory 카드로 표시한다.

## 승인

- 상태: `approved-by-user`
- 날짜: `2026-08-08`
- 근거: 사용자가 FHD·1280×720 소비 화면과 왼쪽 단일 생꼬치 카드, 오른쪽 품질별 읽기 전용 목록,
  그릴 화면의 하단 공용 선반 숨김을 승인했다.

## 픽셀 처리

- `x < 425`: 승인 `BG-WORKSPACE-GRILL R1` 픽셀
- `x >= 425`: 승인 `CM-GRILL-STATION-EMPTY-BASE R1` 픽셀
- 리샘플, 색 보정, 형상 재생성, 손실 압축 없음
