# Artist 000 — D1 네기마용 대파 모델 R1 (superseded)

- 상태: `superseded-by-r2` (2026-07-29)
- ID: `MDL-INGREDIENT-NEGI`
- 규격: `42 / 800 triangles` GLB + `256×192` nearest pixel albedo

승인 D1 조립 화면 재료 통의 **큼직한 네기마용 대파 토막 한 개**를 직접 시각 원본으로 한 bundle이다.
짙은 초록의 골진 외피와 한쪽의 층상 절단면을 보존한다. 다만 대파의 긴 축이 꼬치 축과 나란히 보여 옆면 관통으로 읽히지 않아 사용자 제출 전 R2로 교체했다.
R2는 대파의 긴 축을 `local X`, 꼬치 관통 축을 `local +Y`로 직교시킨다.
꼬치·닭·완성 꼬치·jig·다른 음식은 포함하지 않는다. 앱 manifest와 runtime 등록은 승인 전 금지다.
