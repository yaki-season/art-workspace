# Artist 000 — D1 네기마 조립 전체 화면 R1

- 상태: `approved-by-user` (2026-07-28)
- 화면: `SCR-SVC-ASSEMBLY`
- D1 상태: 생맥주 부분 제공 뒤, 네기마 첫 번째 조립 시작 직전
- 규격: `1920×1080` FHD
- 생성: built-in imagegen, 승인 조립 마스터·승인 손님 화면은 스타일/구도 기준으로만 사용

## 포함

- 원재료 닭다리살 통과 대파 통
- 사용 전 대나무 꼬치 통
- 비어 있는 5칸 꼬치 jig 하나
- 완성 꼬치가 아직 없는 전달 tray 하나
- 상단 주문 rail, 하단 공용 준비 목록/스테이션 전환용 DOM 안전 영역

## 제외

- 손님·좌석·손님 테이블·그릴·생맥주 설비·접시·완성 네기마·서빙 상태
- 수량·품질·타이머·레시피 문구·버튼·커서·화살표·체크·아이콘·패널·텍스트

사용자가 이 화면을 승인했다. 다음은 이 승인본에서 `BG-WORKSPACE-ASSEMBLY`부터 한 자산씩 분리·격리
검수하는 단계다. 그릴 화면 생성과 app runtime 등록은 여전히 후속 승인 게이트다.
