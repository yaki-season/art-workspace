# Artist 000 — D1 조립대 R3

- 상태: `approved-by-user` (2026-07-29)
- ID: `ST-ASSEMBLY-TIER-1`
- 화면: `SCR-SVC-ASSEMBLY`
- 규격: straight-alpha `1920×1080` FHD PNG

승인된 D1 조립 전체 화면을 직접 시각 원본으로 하여 분리한 고정 조립대다. 왼쪽부터 원본의 생 닭고기,
네기마용 큼직한 대파 토막, 미사용 대나무 꼬치가 든 재료 통과 빈 5칸 jig·빈 전달 tray를 포함한다.

jig 위의 대나무 꼬치와 조립물은 고정 래스터에 굽지 않는다. 빈 꼬치가 먼저 별도 동적 레이어로 놓이고,
정상 입력마다 `닭 → 파 → 닭 → 파 → 닭` 한 조각이 그 꼬치에 누적된다.

검수판은 checkerboard 위에 이 투명 레이어 한 장만 표시한다.

사용자가 R3를 승인했다. 다음 단위는 빈 꼬치와 `닭 → 파 → 닭 → 파 → 닭`의 누적 상태를 갖는 동적
조립 state bundle이며, 이 고정 조립대의 runtime 등록은 아직 금지다.
