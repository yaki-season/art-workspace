캐스트 보드는 퇴근 직장인 2인, 혼술 손님, 단골, 커플 2인, 관광객, 리뷰어, 선택적 취객을 구분한다. 퇴근 직장인 2인은 동료이며 커플로 전제하지 않는다. 단골은 기억 주문, 관광객은 추천, 리뷰어는 품질·대기·분위기 평가, 선택적 취객은 짧은 인내와 방해 가능성을 픽토그램으로 표현했다.

유형은 얼굴·나이·옷·자세·소품으로 구분하고 과장된 고정관념은 피했다. 취객은 기본 캠페인 필수 손님이 아닌 잠금 후보로 남겼다.
