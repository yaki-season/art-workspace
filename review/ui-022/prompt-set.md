# UI-022 손님 아트 제작 입력

도구: 내장 image_gen. CLI/API 우회나 로컬 픽셀 보정은 아직 사용하지 않았다.
현재 상태: **외형 방향만 사용자 승인**, 배경·규격 보정과 소비 화면 검수 전. runtime 승격 불가.
사용자 결정 원문: `외형 방향 승인, 보정·인게임 검수 진행`.

## 입력 역할과 제작 명세

읽기 전용 화풍/좌석 기준은 기존 승인 `app/public/assets/core/customer/in-game-mapping/middle-aged-woman-waiting-r9-b1.png`.
각 인물은 한 호출에 한 상태만 생성했다. 다음은 제작에 사용한 프롬프트의 정규화 명세이며 도구 호출 원문을 사후 복원한 로그는 아니다.

공통: 따뜻한 야간 가게의 손그림풍 인물. 자연스러운 비례, 절제된 표정, 연필 선과 과슈 질감, 기존 인물과 같은 전면 조명. 정면으로 앉은 전신, 두 손은 무릎 위. 1920×1080 투명 PNG, 인물 중심 x=960, 좌석 hip anchor y=594, 머리 y=180~300, 최대 인물 폭 280px. 의자·테이블·소품·문자·UI·그림자 배경·체크무늬를 그리지 않는다. 기존 얼굴/의상 재사용 금지.

## 기술 검수

생성 결과는 요청과 달리 1672×941이다. 아카네는 RGBA지만 발 사이 붉은 잔여 픽셀이 있고, 다른 세 인물은 RGB 이미지에 체크무늬 배경이 구워져 있다. 투명 배경 제거 재생성은 형태/크기 변형 및 동일 결함으로 선택하지 않았다. 원본 투명 PNG를 편집하는 추가 재시도는 HTTP 500으로 실패했다.

외형을 보존한 로컬 배경 제거·크기 정규화 사용 여부를 사용자에게 질문했다. 이 확인과 이후 인게임 소비 화면 최종 승인은 별개다. 현재 public/assets에는 복사하지 않았다.

후속 상태는 승인한 각 인물을 edit target으로 삼아 얼굴·옷·하체·캔버스·앵커를 보존하고 손/팔만 변경한다. 실제 네기마 제공 때만 먹기, 실제 생맥주 제공 때만 마시기. 다른 메뉴를 네기마로 바꾸거나 다른 인물의 손동작 이미지를 대체 사용하지 않는다.
